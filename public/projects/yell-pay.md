# YELL PAY

## Project Overview
Payment processing platform focused on secure transaction handling, API integrations, and financial data integrity.

## Requirements
- Secure and atomic transaction processing.
- Integration with multiple third-party payment gateways.
- Real-time fraud detection and auditing.
- High reliability for financial data.

## My Contributions
- **Backend Infrastructure**: Led the development of the core transaction engine using PHP and MySQL.
- **API Integrity**: Implemented idempotent API endpoints to prevent duplicate transactions.
- **Security**: Designed the data encryption and vaulting system for sensitive financial information.

## Solutions
- Used **database transactions** with strict isolation levels to ensure atomicity and consistency.
- Built a **distributed queue system** for asynchronous auditing, ensuring high performance without compromising integrity.
- Integrated **OAuth 2.0** and HMAC signing for all outgoing API requests to third-party providers.
